# Testes Unitários e TDD — Sábado Acadêmico 24/10

Repositório da atividade individual de TDD (ciclo Red-Green-Refactor) com Python e pytest.

## Estrutura

- `meu-exercicio/` — minha implementação da atividade: a função `calcular_taxa_entrega`, os testes automatizados e o registro do ciclo de TDD.
- `referencia-professor/` — cópia do repositório disponibilizado pelo professor (https://github.com/lucianozanuz/pbl-qualidade-software-2026-2), mantida como referência/material de apoio.

## Como rodar os testes

```bash
cd meu-exercicio
python -m pip install -r requirements.txt
python -m pytest -v
```
